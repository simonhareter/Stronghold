Modules:
    main.c — Program entry point

        Opens the window and runs the game loop. It calls the other modules.
        It must not contain all the game logic.

    world.c — Game world

        Stores the map, terrain, and world size. It also provides functions to check if a tile is free or blocked.


    entity.c — Game objects

        Stores common information about objects, such as their position and unique ID. Units and buildings have additional data.

    building.c — Buildings

        Handles building placement, construction, health and building types. Later, it can handle walls, towers, houses and production buildings.

    unit.c — Units

        Handles unit movement, selection, orders and health. Later, it can handle combat and unit behaviour.


    simulation.c — Game rules

        Updates resources, food, production, combat and other rules. This module decides what happens in the game.

    renderer.c — Graphics

        Draws the terrain, sprites, buildings, units, selection indicators and interface. It does not decide game rules.

    input.c — Player controls

        Reads mouse and keyboard input. It handles actions such as selecting a unit or placing a building.
